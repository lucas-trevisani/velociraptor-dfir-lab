# Banco

Tabelas:

- `users`: administradores e clientes.
- `licenses`: chave, status, validade, limite de HWIDs e Hunts permitidas.
- `devices`: HWID, host, plataforma, versao do launcher e ultimo contato.
- `hunts`: cadastro logico da Hunt.
- `hunt_versions`: arquivo, versao, hash e assinatura.
- `results`: artefatos enviados pelo cliente.
- `logs`: auditoria.
- `sessions`: sessoes JWT revogaveis.
